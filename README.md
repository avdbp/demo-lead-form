# skt-forms

Formularios Web-to-Lead (Salesforce) y fragmentos HTML para Scorekeeper / Sales Score Keeper.

## Contenido

- **form-sf.txt** — Plantilla generada por Salesforce (referencia de campos y valores).
- **form-sf.html** — Formulario base alineado con SF.
- **form-email.html** — Variante email marketing.
- **form-linkedin.html** — Variante LinkedIn.
- **form-web.html** — Variante sitio web.
